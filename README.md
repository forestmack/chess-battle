# Chess Battle

Chess with a gold economy. Each side starts with a king, 3 pawns and a knight. Capture pieces to earn gold, spend it to drop reinforcements, and checkmate your opponent.

Play: https://forestmack.github.io/chess-battle/

- Daily challenge, bots (Easy, Medium, Hard), pass & play, and online head to head via invite link
- Online play is peer-to-peer (PeerJS), so no accounts or game server
- Installable as a home-screen app; works offline for bot and pass & play games
